# Contributing to FootyFolio

Thanks for taking a look — this started as a solo final project, and I'd genuinely like help making it better.

## Getting started

1. Fork the repo and clone your fork
2. Follow the setup steps in the [README](./README.md#-run-it-yourself) to get it running locally
3. Create a branch for your change: `git checkout -b fix/thing-youre-fixing`
4. Open a pull request with a short description of what changed and why

## Where to help

Good first areas if you're not sure where to start:
- UI/design polish — the visual layer is still rough in places
- Bug reports — open an issue if something breaks, especially auth or the AI report flow
- Small feature ideas from the roadmap below

## Deferred features (not yet built, open to contributions)

These were cut for the original deadline and are fair game if you want to tackle one:
- Real-time messaging between scouts and players
- Video highlight clips / media uploads
- Coach/team endorsements
- Public shareable player profile links (no login required)
- Email/push notifications
- Smarter scout-side talent recommendations

## Questions

Open an issue or reach out — happy to talk through an idea before you put time into it.
